# DueGuard Success Metrics

## 원칙
- MVP는 "얼마나 많은 사람이 썼는가"가 아니라, **"설치한 사람이 이 앱을 쓸 만한 앱으로 느꼈는가"**를 측정한다.
- DAU, MAU 같은 총량 지표는 MVP 판단에 사용하지 않는다.
- 모든 지표는 **디바이스 로컬 기준 이벤트** 또는 **Firebase Analytics (선택)** 로 수집한다. 서버 DB 구축 금지.

## 핵심 지표 4종

### 1. Install → First Item Creation (설치 후 첫 항목 등록까지 시간)
- 정의: 앱 첫 실행 이벤트(`app_first_open`) 이후 첫 `item_created` 이벤트까지의 경과 시간.
- 목표: **중앙값 2분 이내**, **15분 이내 비율 70% 이상**.
- 실패 판정: 중앙값 5분 초과 또는 7일 내 미등록 비율 50% 초과.
- 해석: 이 시간이 길면 온보딩/첫 화면 설계가 실패한 것이다. 카피나 필드 수부터 의심한다.

### 2. Average Items per User (사용자당 평균 항목 수)
- 정의: 설치 후 7일 시점 기준, `item_created` 누적 카운트 평균. 삭제된 항목도 포함한다.
- 목표: **평균 3건 이상**.
- 실패 판정: 평균 1.5건 이하.
- 해석: 1건만 등록하고 끝났다면 "시험 삼아 써본 것"이지 실사용이 아니다. 3건 이상이면 "생활의 일부"로 편입될 가능성이 있다.

### 3. Notification Opt-in Rate (알림 권한 허용률)
- 정의: 알림 권한 프롬프트 노출 이벤트(`notif_prompt_shown`) 대비 허용 이벤트(`notif_prompt_granted`) 비율.
- 목표: **80% 이상**.
- 실패 판정: 70% 이하.
- 해석: 이 앱은 알림이 없으면 아무 기능도 못한다. 허용률이 낮으면 권한 요청 시점/문구가 잘못된 것이다. (첫 실행 즉시 요청하지 말고, 첫 항목 저장 직후 "이 항목에 알림을 걸까요?" 맥락에서 요청)

### 4. 7-Day Revisit Rate (7일차 재방문율)
- 정의: 설치 후 7일 이내에 `app_open` 이벤트가 2회 이상 발생한 사용자 비율 (첫 실행 제외).
- 목표: **40% 이상**.
- 실패 판정: 25% 이하.
- 해석: 이 앱은 하루 여러 번 여는 앱이 아니다. "알림이 오면 연다"가 정상 패턴이다. 7일 내 최소 한 번 다시 여는 비율이 곧 "실제로 알림이 유효했는가"를 간접 검증한다.

## 요약 목표표

| 지표 | 목표 | 실패 기준 |
|---|---|---|
| 설치 → 첫 항목 등록 (중앙값) | 2분 이내 | 5분 초과 |
| 7일차 평균 항목 수 | 3건 이상 | 1.5건 이하 |
| 알림 권한 허용률 | 80% 이상 | 70% 이하 |
| 7일차 재방문율 | 40% 이상 | 25% 이하 |

## 측정 이벤트 정의 (최소)
| 이벤트 | 발생 시점 | 비고 |
|---|---|---|
| `app_first_open` | 설치 후 최초 실행 | 로컬에서 첫 실행 여부 판정 |
| `app_open` | 매 실행 | 포그라운드 복귀 포함 여부는 구현 시 결정 |
| `notif_prompt_shown` | 알림 권한 요청 직전 | |
| `notif_prompt_granted` | 권한 허용 확인 | |
| `notif_prompt_denied` | 권한 거부 확인 | |
| `item_created` | 새 항목 저장 성공 | 카테고리, repeatType 속성 포함 |
| `item_completed` | 완료 처리 | |
| `item_deleted` | 삭제 처리 | |
| `notif_delivered` | 예약 알림 실제 전달 | 가능한 범위에서 추적. 실패하면 지표에서 제외 |
| `notif_tapped` | 알림 탭으로 앱 진입 | |

## 비목표 (측정하지 않는 것)
- DAU / MAU 총량
- 세션 길이
- 화면별 스크린 뷰
- 광고/매출 지표 (MVP 수익 모델 없음)

MVP 단계에서 위 지표를 추가하면 "많이 쓴다"에 시선이 쏠려서 본래 목표(손실 방지 도구로서의 신뢰성)를 놓친다.
