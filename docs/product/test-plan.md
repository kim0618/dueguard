# DueGuard Internal Test Plan

내부 테스트(비공개 Internal Testing) 중 수행할 실기 시나리오. `docs/engineering/test-cases.md`는 전체 QA 케이스의 상위 집합이고, 본 문서는 **짧은 시간에 반드시 돌려봐야 하는 코어 플로우**에 집중한다.

## 대상
- Android 10(API 29) 이상 실기 1대 이상
- 테스터 ko 1명 이상, en 1명 이상
- 실행 시간: 30~40분

## 체크 기호
- [P] Pass
- [F] Fail (재현 단계와 로그 함께 제출)
- [N] 해당 없음 (이유 기재)

## 1. 설치 & 첫 실행 (5분)

| # | 단계 | 기대 결과 |
|---|---|---|
| 1-1 | 스토어에서 설치 후 첫 실행 | 홈 화면 진입, 권한 요청 다이얼로그 자동으로 뜨지 않음 |
| 1-2 | 앱 언어를 ko, en 각각으로 바꿔 재실행 | 모든 버튼/라벨이 해당 언어로 표시 |
| 1-3 | 앱 이름 | 기기 홈 런처에 "DueGuard"로 표시 |

## 2. 첫 항목 등록 (5분)

| # | 단계 | 기대 결과 |
|---|---|---|
| 2-1 | 제목 미입력 상태에서 저장 | 제목 필드에 "입력 필요" 에러, 저장 실패 |
| 2-2 | 제목만 입력 후 저장 | 저장 성공, 기본 카테고리/반복(once)로 저장됨 |
| 2-3 | 2-2 이후 알림 권한 다이얼로그 | 자동 노출 또는 홈 배너로 권한 요청 가능 |
| 2-4 | 권한 허용 후 홈 복귀 | 상단 배너 사라짐 |
| 2-5 | 권한 거부 후 홈 복귀 | 상단 배너 유지, "허용하기" 버튼에서 다시 시스템 설정으로 이동 가능 |
| 2-6 | 2분 뒤 시각으로 once 저장 | "알림이 예약됐습니다" 토스트, 카드에 "다음 알림" 시각 표시 |
| 2-7 | 2-6 후 2분 대기 | 알림 수신 |

## 3. 수정 / 삭제 (5분)

| # | 단계 | 기대 결과 |
|---|---|---|
| 3-1 | 항목 탭 → 수정 → 제목만 변경 | 저장 후 리스트 카드 제목이 즉시 반영 |
| 3-2 | 항목 수정 → 날짜를 10분 뒤로 변경 | 기존 알림 취소되고 새 시각에 알림 1개만 예약 |
| 3-3 | 항목 스와이프 삭제 | 확인 후 리스트에서 제거, 예약 알림 사라짐 |
| 3-4 | 2-6 설정 후 2-6 시각 도달 전에 삭제 | 원래 시각에 알림 오지 않음 |

## 4. 반복 / 완료 (10분)

| # | 단계 | 기대 결과 |
|---|---|---|
| 4-1 | daily 항목 저장 후 완료 처리 | dueAt이 1일 뒤로 이동, 알림 재예약 |
| 4-2 | weekly 완료 | 7일 뒤로 이동 |
| 4-3 | monthly 15일 완료 | 다음 달 15일로 이동 |
| 4-4 | yearly 7월 20일 완료 | 다음 해 7월 20일로 이동 |
| 4-5 | monthly 31일 선택 → 다음 달이 30일 달인지 확인 | 30일로 당겨 예약 (edge case 실기 확인) |
| 4-6 | once 완료 처리 | "완료됨" 상태, 다음 회차 생성 안 됨 |

## 5. Past-time / Catch-up (5분)

| # | 단계 | 기대 결과 |
|---|---|---|
| 5-1 | 과거 시각으로 once 저장 | 확인 다이얼로그, 확인 시 저장되지만 알림 미예약 |
| 5-2 | 5-1 항목 홈 카드 | "지남" 상대 날짜 표시, "알림 없음" 상태 |
| 5-3 | daily 항목을 과거 시각으로 저장 | dueAt이 다음 유효 회차로 자동 전진, 알림 예약 |
| 5-4 | 기기 시각을 7일 앞으로 변경 후 앱 실행 (테스트용) | catchUp이 repeat 항목들을 현재 이후 시각으로 전진 |

## 6. 기기 재부팅 (2분)

| # | 단계 | 기대 결과 |
|---|---|---|
| 6-1 | 10분 뒤 알림 예약된 상태에서 재부팅 | 부팅 후 10분이 지나면 알림 수신 |
| 6-2 | 6-1 이후 앱을 열지 않고 알림만 확인 | 알림 탭 시 앱 실행 (홈 또는 상세) |

## 7. 로컬라이즈 (3분)

| # | 단계 | 기대 결과 |
|---|---|---|
| 7-1 | 기기 언어 ko | 전부 한국어 |
| 7-2 | 기기 언어 en | 전부 영어, 하드코딩된 한글 노출 없음 |
| 7-3 | 기기 언어 ja (미지원) | 영어로 폴백 |
| 7-4 | 날짜 카드 텍스트 | ko/en 각 포맷 규칙에 맞게 표시 |

## 8. 성능 / 안정성 (5분)

| # | 단계 | 기대 결과 |
|---|---|---|
| 8-1 | 20개 항목 등록 후 스크롤 | 렉 없음, 크래시 없음 |
| 8-2 | 비행기 모드 | 전 기능 정상 (서버 호출 없음) |
| 8-3 | 앱 강제 종료 후 재실행 | 저장된 항목 유지 |
| 8-4 | 저장소가 매우 부족한 상태 | "저장 실패" 토스트, 크래시 없음 |

## 릴리즈 판단 기준
- Critical(알림 미수신, 저장 실패, 크래시) 항목 0건
- Medium(로컬라이즈/문구/사소한 UI) 항목 ≤ 5건, 다음 릴리즈로 이관 가능
