# DueGuard User Stories

## 타깃 사용자 3종

### 1. 1인 가구 직장인 (20대 후반 - 30대 중반)
- 월세, 관리비, 카드 대금, 통신비, 넷플릭스/쿠팡와우 같은 구독이 여기저기 흩어져 있다.
- 자동이체가 걸려 있어도 잔액 부족으로 연체되는 일이 종종 있다.
- 다 각각 앱/문자/이메일에서 알림이 오지만, 정작 "내가 언제 얼마를 내야 하는지" 한눈에 안 보인다.

**Pain point**
- 돈이 나가는 날짜가 기억나지 않는다.
- 자동결제로 새는 돈이 있는 것 같은데 점검을 못한다.
- 캘린더 앱에 일정과 약속이 섞여 있어서 중요한 납부일이 묻힌다.

### 2. 자영업자 / 프리랜서 (30-40대)
- 사업자 세금 신고(부가세, 종합소득세), 임대료, 4대 보험 납부 등 날짜를 놓치면 가산세 또는 과태료가 붙는다.
- 법인 카드, 개인 카드, 사업자 계좌가 분리되어 있어 결제일이 더 복잡하다.
- 놓치면 단순 불편이 아니라 "실제 손해 금액"이 크다.

**Pain point**
- 분기/반기/연 단위로 돌아오는 세무 일정이 헷갈린다.
- 세무사가 알려주긴 하지만 본인도 체크 리스트가 필요하다.
- 일반 To-Do 앱에 넣으면 다른 업무 태스크에 섞여서 묻힌다.

### 3. 집안일 담당 가족 구성원 (30-50대)
- 관리비, 전기세, 가스비, 자동차 보험 갱신, 정기 검진, 아이 학원비 자동결제일 등을 다 기억하고 있다.
- 배우자/가족의 일정까지 본인이 관리하는 경우가 많다.
- 현재는 냉장고 메모, 카카오톡 나에게 보내기, 수첩 등으로 분산 관리.

**Pain point**
- 1년 단위 일정(보험 갱신, 자동차 정기점검, 건강검진)을 놓친다.
- 기억에만 의존하다가 한 번 놓치면 큰 금액이 들어간다.
- 메모 앱은 "알림"이 약해서 실제로 까먹는다.

> MVP에서 "가족 공유"는 하지 않는다. 이 사용자는 자기 기기에서 혼자 관리하는 것으로 가정한다.

## 핵심 사용자 시나리오 5개

### 시나리오 1: 카드 대금 매달 놓치던 사람
1. 앱 설치 후 홈에서 "항목 추가" 버튼이 가장 크게 보인다.
2. 제목 "OO카드 결제일" 입력, 카테고리 "카드/결제", 날짜 매달 25일, 반복 monthly 선택.
3. 저장 즉시 "다음 알림: N월 25일 09:00"이 카드에 표시된다.
4. 1개월 뒤 해당 날짜에 로컬 알림이 도착하고, 사용자는 탭해 앱을 연다.
5. "완료" 버튼을 누르면 자동으로 다음 회차가 한 달 뒤로 세팅된다.

### 시나리오 2: 무료 체험이 유료로 자동 전환되는 것을 막고 싶은 사람
1. 구독 시작 시 "N일 무료 체험" 문구를 보고 앱을 연다.
2. 제목 "XX 서비스 해지 여부 결정", 카테고리 "구독", 날짜는 체험 만료 1일 전, 반복 once.
3. 해당 날짜에 알림이 오고, 사용자는 실제로 해지 또는 유지 결정을 한다.
4. 결정 후 앱에서 해당 항목을 삭제한다. 알림도 함께 취소된다.

### 시나리오 3: 자영업자 부가세 신고
1. 세무사에게 "7월 25일까지 부가세 신고"라고 듣는다.
2. 제목 "부가세 신고", 카테고리 "세금", 날짜 7월 20일(여유 5일), 반복 yearly.
3. 매년 같은 달/일에 자동으로 돌아온다.
4. 완료 처리 시 내년 동일 날짜로 자동 갱신된다.

### 시나리오 4: 1년마다 돌아오는 자동차 보험 갱신
1. 보험 갱신 안내 문자를 받고 앱을 연다.
2. 제목 "자동차 보험 갱신", 카테고리 "보험", 날짜 만기 7일 전, 반복 yearly.
3. 1년 뒤 알림 수신. 갱신 비교 후 완료 처리.
4. 다음 해로 자동 이월.

### 시나리오 5: 며칠 뒤 다시 여는 순간
1. 첫 등록 후 2-3일이 지나 알림이 울린다.
2. 사용자는 알림을 탭해 앱을 연다.
3. 홈 화면은 "오늘/임박/예정" 3단 구조로, 가장 위에 오늘 건이 크게 보인다.
4. 완료 버튼 한 번으로 처리되는 경험에서 "이 앱은 계속 쓸 만하다"고 느낀다.
5. 이 시점에 추가 항목을 1-2개 더 등록한다. (평균 3건 이상이 목표)

## 설치 후 1분 내 사용자가 이해해야 하는 핵심 가치

사용자가 앱을 열고 60초 안에 다음 세 가지가 전달되어야 한다.

1. **"이 앱은 돈 나가는 일정만 다룬다"**
   - 첫 화면 카피가 "오늘 해야 할 일"이 아니라 "곧 돈이 나갈 일정"이다.
   - 카테고리도 일반 To-Do(업무/운동/쇼핑)가 아니라 금전 맥락(카드, 구독, 세금, 보험, 공과금)으로 고정되어 있다.

2. **"등록이 아주 빠르다"**
   - 제목 + 날짜 + 카테고리 + 반복 4개 필드만. 15초 이내 완료.
   - 기본값이 최대한 똑똑해서 대부분 사용자는 제목만 입력하고 저장이 가능해야 한다.

3. **"알림이 실제로 온다"**
   - 저장하는 순간 "다음 알림: YYYY-MM-DD HH:mm" 문구를 카드에 표시해서, 예약이 실제로 걸렸음을 확인시킨다.
   - 알림 권한을 허용하지 않으면 홈 상단에 "알림이 꺼져 있습니다. 이 앱은 알림이 핵심입니다" 경고를 반드시 노출한다.

세 가지를 다 전달하지 못하면 MVP 포지셔닝 실패로 간주한다.
