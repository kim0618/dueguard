# DueGuard Wireframes

텍스트 기반 화면 설계 문서다.
픽셀 수치는 개략적인 가이드이며, 실제 구현 시 Material 3 스펙을 우선한다.
4개 화면만 다룬다: 홈 / 추가(수정) / 상세 / 설정.

---

## 공통 구조

```
┌──────────────────────────────────────┐
│  StatusBar (system)                  │
├──────────────────────────────────────┤
│  AppBar                              │
├──────────────────────────────────────┤
│  [알림 권한 배너 - 조건부]             │
├──────────────────────────────────────┤
│                                      │
│  Content Area (scrollable)           │
│                                      │
├──────────────────────────────────────┤
│  [FAB - 홈에만]                      │
└──────────────────────────────────────┘
```

- 바텀 네비게이션 없음
- 설정은 홈 AppBar의 아이콘 버튼으로 진입
- 뒤로가기는 AppBar back button (안드로이드 시스템 제스처 + AppBar 버튼 동시 지원)

## Screen 1: 홈 (Home)

### 화면 목적
등록된 항목의 다가오는 일정을 확인하고, 완료 처리하거나 새 항목을 추가한다.
"오늘/이번 주/예정" 3단으로 긴급도를 시각적으로 구분한다.

### 레이아웃

```
┌──────────────────────────────────────┐
│  ≡  DueGuard                ⚙        │  AppBar
├──────────────────────────────────────┤
│ ⚠ 알림이 꺼져 있어요. 이 앱은 알림이  │  MaterialBanner (조건부)
│   핵심입니다.              [허용하기] │
├──────────────────────────────────────┤
│                                      │
│  오늘 (Today)                        │  섹션 헤더
│  ┌────────────────────────────────┐  │
│  │▍카드/결제  OO카드 결제일    ✓  │  │  ReminderCard (red accent)
│  │  오늘 · 매달 · 다음 알림: 오늘 │  │
│  └────────────────────────────────┘  │
│                                      │
│  이번 주 (This week)                  │  섹션 헤더
│  ┌────────────────────────────────┐  │
│  │▍보험  자동차 보험 갱신       ✓ │  │  ReminderCard (orange accent)
│  │  3일 뒤 · 매년               │  │
│  └────────────────────────────────┘  │
│                                      │
│  예정 (Upcoming)                     │  섹션 헤더
│  ┌────────────────────────────────┐  │
│  │  구독  넷플릭스              ✓ │  │  ReminderCard (no accent)
│  │  12일 뒤 · 매달              │  │
│  └────────────────────────────────┘  │
│  ┌────────────────────────────────┐  │
│  │  세금  부가세 신고            ✓ │  │  ReminderCard
│  │  28일 뒤 · 매년              │  │
│  └────────────────────────────────┘  │
│                                      │
│                              [+ 항목 추가]  │  FAB (Extended)
└──────────────────────────────────────┘
```

### 주요 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| AppBar | 좌측: 앱 이름 "DueGuard", 우측: settings 아이콘 버튼 |
| MaterialBanner | 알림 권한 미허용 시만 노출. `notifications_off` 아이콘 + 경고 텍스트 + 허용 버튼 |
| 섹션 헤더 | "오늘" / "이번 주" / "예정" 텍스트. 해당 항목 없으면 섹션 전체 숨김 |
| ReminderCard | 카테고리 아이콘, 제목, 날짜 상대 표현, 반복 라벨, 다음 알림 문구, trailing 완료 버튼 |
| FAB | `FloatingActionButton.extended`, 라벨: `add_item_fab` ARB 키 |

### CTA

- 주요: FAB "항목 추가" - 추가 화면으로 이동
- 보조: 카드 trailing ✓ 버튼 - 완료 처리 확인 다이얼로그
- 보조: 카드 탭 - 상세 화면으로 이동
- 보조: 카드 우측 스와이프 - 삭제 확인 다이얼로그 트리거

### 빈 상태

항목이 하나도 없을 때:
```
┌──────────────────────────────────────┐
│  ≡  DueGuard                ⚙        │
├──────────────────────────────────────┤
│                                      │
│        [notifications_none 48dp]     │
│                                      │
│      아직 등록된 항목이 없어요        │  home_empty_title
│   카드 대금, 구독 갱신, 보험 날짜 -   │  home_empty_body
│   잊기 전에 등록해두세요.             │
│                                      │
│              [+ 항목 추가]            │  FAB
└──────────────────────────────────────┘
```

### 섹션 정의 (구현 기준)

| 섹션 | 조건 |
|---|---|
| 오늘 | `dueAt.localDate == today` |
| 이번 주 | `dueAt` 이 tomorrow ~ today+7 범위 |
| 예정 | `dueAt` > today+7 |

- 지난 항목(`dueAt < today`)은 홈 리스트에서 제외하지 않는다. "오늘" 섹션 상단에 표시하되, 카드에 "N일 지남" 상대 표현 사용.
- 완료 처리된 항목은 홈 리스트에서 즉시 제거.

## Screen 2: 항목 추가 / 수정 (Add / Edit)

### 화면 목적
최소 입력으로 항목을 저장한다. 15초 이내 완료가 목표.
제목 + 날짜 + 카테고리 + 반복 4개 필드. 나머지는 선택.

### 레이아웃

```
┌──────────────────────────────────────┐
│  ←  항목 추가                        │  AppBar (수정 시 "항목 수정")
├──────────────────────────────────────┤
│                                      │
│  항목 이름 *                          │  TextField label
│  ┌────────────────────────────────┐  │
│  │ 예: OO카드 결제일              │  │  hint text
│  └────────────────────────────────┘  │
│                                      │
│  카테고리 *                           │  FilterChip 그룹
│  [카드/결제] [구독] [공과금] [세금]   │
│  [보험] [대출/이자] [기타]            │
│                                      │
│  날짜 및 시간 *                       │  ListTile (탭 시 DatePicker)
│  ┌────────────────────────────────┐  │
│  │  📅  N월 N일 (X) 오전 9:00     │  │
│  └────────────────────────────────┘  │
│                                      │
│  반복                                │  DropdownButtonFormField
│  ┌────────────────────────────────┐  │
│  │  1회 ▾                        │  │
│  └────────────────────────────────┘  │
│                                      │
│  메모 (선택)                          │  TextField (multiline)
│  ┌────────────────────────────────┐  │
│  │ 추가로 기억할 내용              │  │
│  └────────────────────────────────┘  │
│                                      │
│                                      │
│  ┌────────────────────────────────┐  │
│  │              저장               │  │  ElevatedButton (full width)
│  └────────────────────────────────┘  │
│                                      │
└──────────────────────────────────────┘
```

### 주요 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| AppBar | 좌측: back button (취소), 제목: `item_add_title` or `item_edit_title` |
| 항목 이름 TextField | `autofocus: true`. 진입 시 키보드 자동 올라옴. `maxLength: 80` |
| 카테고리 FilterChip 그룹 | 7개 칩. 기본 선택: 마지막 선택 카테고리 (SharedPreferences). 1개만 선택 가능. |
| 날짜 ListTile | 탭 시 `showDatePicker` 이후 `showTimePicker` 순서 진행. 기본값: 오늘 또는 내일 09:00 |
| 반복 Dropdown | `repeat_once` ~ `repeat_yearly` 5개 항목. 기본: `once` |
| 메모 TextField | 선택 필드. `maxLines: 3`. 없어도 저장 가능. |
| 저장 버튼 | `ElevatedButton`, 전체 너비. 저장 중 `CircularProgressIndicator`로 교체. |

### CTA

- 주요: 저장 버튼 - 유효성 검사 후 DB 저장 + 알림 예약 + 홈으로 복귀 + SnackBar "저장됐습니다"
- 보조: AppBar back - 변경사항 있으면 "저장하지 않고 나가시겠어요?" 다이얼로그 (입력 없으면 즉시 이탈)
- 보조: 카테고리 칩 선택 - 즉시 반영 (다이얼로그 없음)

### 유효성 검사 규칙

| 필드 | 규칙 | 오류 메시지 ARB 키 |
|---|---|---|
| 항목 이름 | trim 후 1자 이상 | `error_title_required` |
| 날짜 | 필수 선택 | `error_date_required` |
| 날짜 (과거) | 경고만, 저장 허용 | `error_date_past` (SnackBar 경고) |
| 카테고리 | 기본값 있으므로 항상 선택된 상태 | - |
| 반복 | 기본값 있음 | - |

### 기본값 자동 적용 (15초 목표 핵심)

```
항목 이름: 비어있음 (autofocus로 즉시 입력 가능)
카테고리: 마지막 선택 카테고리
날짜: 오늘 날짜, 시간 09:00 (이미 지났으면 내일 09:00)
반복: once
메모: 비어있음
```

### 화면 목적
저장된 항목의 전체 정보를 확인한다. 수정 또는 삭제로 이동하는 진입점.
직접 편집 기능은 이 화면에 없다 (수정 버튼 탭 시 추가/수정 화면으로 이동).

```
┌──────────────────────────────────────┐
│  ←  상세 정보              [수정]    │  AppBar
├──────────────────────────────────────┤
│                                      │
│  ┌────────────────────────────────┐  │
│  │  [카테고리 아이콘 32dp]         │  │  Card (헤더 영역)
│  │  OO카드 결제일                  │  │  titleLarge
│  │  카드/결제                     │  │  bodyMedium (Grey)
│  └────────────────────────────────┘  │
│                                      │
│  ─────────────────────────────────   │  Divider
│                                      │
│  날짜 및 시간                         │  ListTile
│  2026년 4월 25일 (토) 오전 9:00      │
│                                      │
│  반복                                │  ListTile
│  매달                                │
│                                      │
│  다음 알림                            │  ListTile
│  🔔 4월 25일 오전 9:00               │  (알림 없으면 🔕 + 경고 텍스트)
│                                      │
│  완료 횟수                            │  ListTile
```

### 주요 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| AppBar | 좌측: back button, 우측: "수정" TextButton (item_edit_title 화면으로 이동) |
| 헤더 카드 | 카테고리 아이콘 + 제목 + 카테고리 라벨 |
| 날짜 ListTile | 상세 포맷 (`y년 M월 d일 (E) a h:mm`) |
| 반복 ListTile | 반복 라벨 |
| 다음 알림 ListTile | 알림 예약 상태 표시. 알림 없으면 `notifications_off` 아이콘 + 권한 안내 |
| 완료 횟수 ListTile | `completedCount`가 0이면 "아직 완료 없음" |
| 메모 ListTile | `note`가 null이면 섹션 자체 숨김 |
| 완료 처리 버튼 | `OutlinedButton`. 탭 시 확인 다이얼로그 |
| 삭제 버튼 | `TextButton` (Error color). 탭 시 확인 다이얼로그 |

### CTA

- 주요: 완료 처리 - 반복 여부에 따라 확인 다이얼로그 분기 후 처리
- 보조: 수정 - 추가/수정 화면으로 이동 (현재 값 pre-fill)
- 보조: 삭제 - 확인 다이얼로그 후 삭제 + 알림 취소 + 홈으로 복귀

### 빈 상태

상세 화면은 항상 특정 항목의 데이터를 보여주므로 빈 상태 없음.
항목이 삭제된 경우(딥링크 등) 홈으로 즉시 복귀.

## Screen 4: 설정 (Settings)

### 화면 목적
알림 권한 상태 확인, 앱 정보 확인.
MVP에서는 기능이 최소화된다. 설정 항목을 늘리지 않는다.

### 레이아웃

```
┌──────────────────────────────────────┐
│  ←  설정                             │  AppBar
├──────────────────────────────────────┤
│                                      │
│  알림                                │  섹션 헤더 (bodySmall, Grey)
│  ─────────────────────────────────   │
│                                      │
│  알림 권한              [허용됨 ✓]   │  ListTile (SwitchListTile)
│  날짜가 되면 알림을 드립니다.         │  (권한 없으면 [허용 필요 !] + 빨간 텍스트)
│                                      │
│  ─────────────────────────────────   │
│                                      │
│  앱 정보                             │  섹션 헤더
│  ─────────────────────────────────   │
│                                      │
│  버전                        1.0.0   │  ListTile (trailing: 버전)
│                                      │
│  오픈소스 라이선스                    │  ListTile (탭 시 OS 라이선스 화면)
│                                      │
│  앱 소개                             │  ListTile (탭 시 about 텍스트 다이얼로그)
│  DueGuard는 놓치면 돈이 나가는       │  (subtitle 2줄)
│  일정을 알려주는 앱입니다.            │
│                                      │
└──────────────────────────────────────┘
```

### 주요 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| AppBar | 좌측: back button, 제목: `settings_title` |
| 알림 권한 ListTile | `permission_handler` 패키지로 현재 권한 상태 조회. 허용이면 체크 표시, 미허용이면 탭 시 `openAppSettings()` |
| 버전 ListTile | `package_info_plus`로 버전 조회 |
| 오픈소스 라이선스 | `showLicensePage()` Flutter 내장 |
| 앱 소개 | `about_app_description` ARB 키 텍스트 |

### CTA

- 주요: 알림 권한 탭 (미허용 시) - 시스템 앱 설정으로 이동
- 보조: 오픈소스 라이선스 탭 - 라이선스 화면

### 빈 상태

설정 화면은 빈 상태 없음. 항상 고정 항목만 표시.

## 화면 전환 맵

```
홈
├── FAB "항목 추가" → 추가 화면
│   └── 저장 / back → 홈
├── 카드 탭 → 상세 화면
│   ├── "수정" → 수정 화면
│   │   └── 저장 / back → 상세 화면 또는 홈
│   ├── "완료 처리" → 확인 다이얼로그 → 홈
│   └── "삭제" → 확인 다이얼로그 → 홈
├── 카드 ✓ 버튼 → 확인 다이얼로그 → 홈 갱신
├── AppBar ⚙ → 설정 화면
│   └── back → 홈
└── 알림 배너 [허용하기] → 시스템 권한 요청
```

## 구현 시 주의 사항

- 바텀 시트(BottomSheet) 사용 금지. 모든 입력은 전체 화면 또는 다이얼로그로만.
- 화면 추가 금지. 위 4개 화면 외 신규 라우트 없음.
- 상세 화면은 `ReminderItem`의 현재 DB 상태를 직접 읽는다. 홈 리스트에서 넘긴 객체를 캐싱하면 수정 후 stale 데이터 표시 위험.
- 수정 화면은 추가 화면과 동일 위젯을 재사용한다. `itemId`를 파라미터로 받아 null이면 추가, 있으면 수정 모드.
